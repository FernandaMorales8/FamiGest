# FamiGest

## Descripción del proyecto

FamiGest es una aplicación móvil educativa orientada al aprendizaje inicial de Lengua de Señas Mexicana (LSM) dentro del entorno familiar.

El proyecto busca reducir la brecha de comunicación entre personas con discapacidad auditiva y sus familiares mediante una herramienta accesible que combine contenido educativo con retroalimentación automática durante la práctica de señas.

La solución utiliza reconocimiento de gestos basado en visión por computadora para analizar la configuración de la mano mediante puntos clave (landmarks) y proporcionar una evaluación inmediata del desempeño del usuario.

---

## Objetivo general

Desarrollar un prototipo funcional de una aplicación móvil que permita a familiares de personas con discapacidad auditiva aprender y practicar señas básicas de LSM mediante lecciones guiadas y un sistema de retroalimentación automática.
